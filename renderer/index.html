    Bookmark syncer

    All your browsers' bookmarks in one library: merged, sorted and cleaned up, and the clean-up can be synced back to the browsers.

    What the colors mean

It may still work in your browser Dead link: page not found (404/410) or the site no longer exists. The details panel offers the Wayback Machine copy No dot: not checked yet.     How it works

    1. Import reads Chrome, Edge, Brave, Vivaldi, Opera and Firefox on this PC, or a bookmarks.html file. The same page saved in several browsers becomes one entry.
    2. Auto-categorize sorts the bookmarks in the current view. Choose built-in rules, local AI (Ollama) or Claude under ⚙. Right-click a category to rename it, merge it into another, or remove it.
    3. Check links finds dead pages. Long runs can be stopped with Cancel on the progress bar; finished work is kept. Rediscover opens a random bookmark.
    4. Clean up: tick bookmarks to delete them or change many at once, or right-click Dead links / Not opened in a year → Delete all. Recently deleted can restore them.
    5. Sync to browsers removes what you deleted from the browsers too (close them first; every file is backed up).
    6. Export saves the current view as a bookmarks.html any browser can import.

    Using it

    Delete bookmarks in this app as usual. Then, with this app open, click the extension's icon in each browser. It shows which bookmarks it found and deletes them when you confirm. It can undo the last run.

    Type an existing category's name to merge into it.

    Sync deletions to browsers

    Removes the bookmarks you deleted in this app from your browsers' own bookmarks. Each browser must be fully closed, and every file is backed up first.

    Chrome or Edge with sync turned on? Use the helper extension for those. It deletes through the browser itself, so sync keeps them deleted, and the browser can stay open.

    Restore from backup

    Before Sync to browsers changes a browser's bookmarks, it saves the old file. Restoring puts that file back as it was. The browser must be closed. Bookmarks added or changed in that browser since the backup are lost, but the current file is backed up first, so you can switch back.

    Chrome or Edge with sync turned on may delete the restored bookmarks again. If so, restore them in the browser's own bookmark manager instead.
